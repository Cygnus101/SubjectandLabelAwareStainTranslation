# Label- & Subject-Aware Augmented CycleGAN for Histopathology Stain Translation

This repository implements a **weakly-supervised stain translation framework** that augments CycleGAN with *slide-level label awareness and subject identity consistency*.  
Goal: Improve **H&E ↔ Reticulin** stain conversion while preserving **clinical morphology**, stain semantics, and patient identity.
